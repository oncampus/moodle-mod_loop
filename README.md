# moodle_mod_loop
Moodle Activity for Loop Links

Für alle Moodle die nicht über Moodalis gesteuert werden (also NICHT VFH, Projects, ...). 
Für diese Moodles existiert zur Zeit noch eine andere Loop Aktivität. 
Beide sollen in Zukunft zu einer Version zusammengefasst werden.

Bei der Installation muss ein Token vergeben werden. 
Dieses ist in Moodalis in der Lernraumverwaltung unter LOOP-Token einzutragen. 

An jedem LOOP das für den jeweiligen Lernraum freigeschaltet werden soll muss der Zuagang einzeln freigeschaltet werden.
